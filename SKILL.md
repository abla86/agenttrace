# SKILL.md

## Purpose
Local security laboratory for evaluating AI-agent security workflows and provenance.

## Skills demonstrated
- Agent security evaluation
- Prompt/taint/provenance modelling
- Capability and tool-integrity policy
- Bounded attack simulation
- Audit and trace evidence
- Reproducible state/decision modelling
- Visual War-Room integration

## Safety boundary
Generated attack material is inert simulation data. Autonomous experimentation is bounded to controlled local scenarios and does not silently modify or deploy production systems.

## Evidence rule
Detection, prevention, latency and security claims require measured, reproducible evidence.
