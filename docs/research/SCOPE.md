# Research scope

AgentTrace is a controlled local evaluation laboratory.

It does NOT claim:
- universal prompt-injection prevention
- a universal zero-day detector
- secure execution of arbitrary untrusted code
- autonomous modification of production source code
- semantic proof of tool safety from hashing alone

The experiment unit is:

attack
-> mutation
-> provenance
-> taint
-> intent
-> requested capability
-> tool integrity
-> policy
-> defense
-> outcome
-> trace

Research hypotheses must be tested rather than asserted.

Primary measurable outcomes:
- attack success rate
- detection rate
- false-positive rate
- attempts to breakthrough
- time to detection
- time to block
- policy coverage
- provenance violations
- tool-drift detection
- behavior drift
- intent drift
- reproducibility
